[odata-support.md](./odata-support.md), чтобы понимать границы.

**Ищу сигнатуру или тип** → [api.md](./api.md).

[architecture.md](./architecture.md), план задач — в [roadmap.md](./roadmap.md).

## Три вещи, которые удивляют в первую очередь

1. **`$count` включён по умолчанию.** Ответ по умолчанию — `{ items, count }`, а не массив.
   Отклонение от спецификации OData. Подробности: [odata-support.md](./odata-support.md#count-включён-по-умолчанию).
2. **`alias` не произвольный.** Он обязан совпадать с именем класса сущности или именем её
   таблицы — по нему ищутся метаданные. `createQueryBuilder('u')` работать не будет
   ([audit.md](./audit.md), A-03).
3. **Приоритет `not` ниже, чем в спецификации.** Парсер читает `not (X) and Y` как
   `not (X and Y)`; нужны явные скобки. Подробности:
   [odata-support.md](./odata-support.md#приоритет-not).
