Конструктор OData-запросов

Соберите запрос полями формы, посмотрите на получившийся URL и выполните его. Данные живые — их отдаёт odata-v4-typeorm-improved поверх TypeORM и SQLite.

Сравнения eq ne gt ge lt le, логика and or not, арифметика add sub mul div mod, функции contains startswith tolower length substring year.

Выключен по умолчанию, как требует OData: отсутствующий $count означает false, и ответом будет обычный массив. Включите, чтобы получить общее число строк по фильтрам — без учёта $top и $skip.
